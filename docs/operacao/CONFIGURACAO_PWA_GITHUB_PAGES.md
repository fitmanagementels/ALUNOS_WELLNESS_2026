# Configuração do PWA XSTEAM

A arquitetura atual não usa OAuth público nem uma implantação `API Executable`. O procedimento vigente está em [CONFIGURACAO_PWA_PUBLICO.md](./CONFIGURACAO_PWA_PUBLICO.md).

O fluxo ativo é:

```text
GitHub Pages → Cloudflare Worker → Apps Script Web App → planilha mestre
```

Use somente o guia vigente para configuração, recuperação, publicação e validação.
