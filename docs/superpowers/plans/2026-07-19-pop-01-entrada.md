# POP da 01_ENTRADA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um POP em PDF de duas páginas dentro da `01_ENTRADA` sem que o manual invalide os lotes de importação.

**Architecture:** A descoberta de entrada filtrará somente o nome reservado do POP antes de validar o lote. O manual será mantido como HTML de impressão versionado e exportado por Chrome para um PDF A4 estático; a cópia final poderá ser enviada à pasta de entrada do Drive.

**Tech Stack:** Google Apps Script V8, Node.js `node:test`, HTML/CSS, Google Chrome headless.

## Global Constraints

- Nome reservado do manual: `LEIA-ME_POP_01_ENTRADA.pdf`.
- Ignorar somente esse nome, sem distinguir maiúsculas de minúsculas.
- Todo outro arquivo continua participando da validação de lote.
- Um lote válido possui exatamente três relatórios `.xls`: `vencimentos`, `fichas` e `avaliacao_fisica`.
- Os três relatórios devem ter a mesma data `AAAA-MM-DD` e revisão `rNN`.
- O POP deve ter duas páginas A4 e conter as três nomenclaturas literais.
- Não usar dados reais de alunos.

- [ ] **Step 3: Implementar o filtro mínimo**

Em `apps-script/05_DriveRepositorio.gs`, adicionar antes de `listarArquivosEntrada`:

```javascript
var NOME_POP_ENTRADA = 'leia-me_pop_01_entrada.pdf';

function filtrarArquivosOperacionaisEntrada_(arquivos) {
  return arquivos.filter(function (arquivo) {
    return String(arquivo.nome || '').toLowerCase() !== NOME_POP_ENTRADA;
  });
}
```

Em `inspecionarPastaEntrada`, trocar `var arquivos = listarArquivosEntrada();` por `var arquivos = filtrarArquivosOperacionaisEntrada_(listarArquivosEntrada());`.

Em `07_ImportacaoService.gs`, aplicar o mesmo filtro à lista recebida antes de chamar `agruparLote`.
